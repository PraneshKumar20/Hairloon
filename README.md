A sleek, AI-powered web application that helps users discover the perfect hairstyles based on their facial geometry and seamlessly connects them with top-rated local salons. Designed with luxury monochrome aesthetics and cinematic loading experiences.

---

## ✨ Highlights & Features

- **AI Face Shape Analysis**: Upload a photo to analyze facial geometry (shape, density, symmetry) and receive tailored style recommendations.
- **Cinematic Experience**: Luxury monochrome login screens and smooth, cinematic loading sequences for a premium feel.
- **Curated Hairstyle Matches**: Algorithm-driven style matching percentages (e.g., 98% Match) tailored to individual facial structure.
- **Salon Discovery & Booking**: Find verified partner salons near you with live ratings, reviews, and distance, complete with an interactive appointment booking flow.
- **Responsive & Accessible**: Optimized for all devices with smooth UI transitions and intuitive navigation.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Modern CSS3 (Custom design system, Glassmorphism, Luxury Monochrome)
- **Icons**: Lucide React
- **Routing**: React Router v7
- **Data Architecture**: Decoupled mock data store for lightning-fast frontend performance

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PraneshKumar20/Hairloon.git
   cd Hairloon
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
